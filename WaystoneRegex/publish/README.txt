PoE2 Waystone Regex v1.0
========================

EN
--
A regex builder for the Path of Exile 2 stash search box (waystones, patch 0.5).

How to use:
1. Run WaystoneRegex.exe — no installation and no .NET required (Windows 10/11 x64).
2. Set MIN/MAX values, modifiers and corrupt filter, then press COPY.
3. Paste the regex into the in-game stash search box.
4. Save your regexes, tag them, and share them as .wsrx files
   (SAVED REGEXES tab -> EXPORT / LOAD FROM FILE, or drop files onto the list).

Note: Windows SmartScreen may warn on first run because the exe is unsigned.
Click "More info" -> "Run anyway".

Your data (saved regexes, settings) is stored in %AppData%\WaystoneRegex.

TR
--
Path of Exile 2 stash arama kutusu için waystone regex oluşturucu (0.5 yaması).

Kullanım:
1. WaystoneRegex.exe'yi çalıştır — kurulum ve .NET gerekmez (Windows 10/11 x64).
2. MIN/MAX değerlerini, modifier ve corrupt filtrelerini ayarla, COPY'ye bas.
3. Regex'i oyundaki stash arama kutusuna yapıştır.
4. Regexlerini kaydet, etiketle ve .wsrx dosyası olarak paylaş
   (SAVED REGEXES sekmesi -> EXPORT / LOAD FROM FILE, ya da dosyayı listeye sürükle).

Not: Exe imzasız olduğu için ilk açılışta Windows SmartScreen uyarabilir.
"Daha fazla bilgi" -> "Yine de çalıştır" ile geç.

Verilerin (kayıtlı regexler, ayarlar) %AppData%\WaystoneRegex klasöründe tutulur.
